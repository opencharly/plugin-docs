# 2026.277.1529 — feat(docs): project SOUL.md to the opencharly.ai site

## Summary

Adds the **SOUL projection** to the docs generator: `SOUL.md` — the identity of charly and every
charly agent — is now published on the site as `soul.md`, alongside the
other root-narrative pages the generator already projects (`VISION.md`, `GRIEVANCES.md`,
`LIBERATION.md`, `README.md`). The file itself is carried by **opencharly/charly#789** (tracked by
umbrella issue opencharly/charly#787).

`gen_soul.go` mirrors `gen_vision.go` exactly: it publishes the source verbatim apart from the one
mechanical edit every root page gets — the source H1 is dropped, because Starlight renders the
frontmatter title (`"Who We Are"`) as the page heading, so keeping the H1 would show the title
twice. It deliberately carries **no link-rewrite map**, because `SOUL.md` is self-contained by
design (it cites no other document and has no repo-relative links); a future link would be caught
by the whole-site link gate like any other page — which is the point of projecting it rather than
transcribing it.

Changes:

- `candy/plugin-docs/gen_soul.go` (new) — the projection.
- `candy/plugin-docs/gen_soul_test.go` (new) — the published body, the generated header, the
  dropped H1, and the absent-source error (the same pair `gen_liberation_test.go` carries).
- `candy/plugin-docs/generate.go` — wire `generateSoul` into the pipeline. The count comment
  ("cleared exceeds the printed sum by five") becomes **six**, since the emitted page set grew by
  one.
- `candy/plugin-docs/generate_test.go` — add `soul.md`/`generateSoul` to the leaf-wiring table, so
  a dropped call site fails by name.
- `candy/plugin-docs/testdata/project/SOUL.md` +
  `candy/plugin-docs/testdata/bed-fixture/project/SOUL.md` (new) — the two hermetic fixture roots
  carry a `SOUL.md`, as they already carry the other root narratives.
- `candy/plugin-docs/catalog_test.go` — the in-memory `TestGenerateRegenNoOp` fixture root gains a
  `SOUL.md`.
- `charly.yml` — the `docs-resolve` R10 bed gains a **fifth plan step** witnessing the new path,
  and its header/description prose is swept from "THREE generator paths" to "FOUR".

**Producer-first.** This is the generator leg of a multi-repo chain: the docs site can only show
`soul.md` once (a) this change has merged and released, and (b) opencharly/charly#789 (`SOUL.md`)
has merged, so the docs repo's `deploy.yml` can pin both. It does not touch the docs repo.
